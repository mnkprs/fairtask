# Data sources

| File | What | Publisher | Fetched from | Integrity |
|---|---|---|---|---|
| `ensembled_annotations_public.csv` (committed; 1,755,900 bytes, 1,699 rows) | Human annotations for 1,699 SWE-bench test instances: `underspecified` and `false_negative` (0–3, max over three annotators), `other_major_issues`, `difficulty`, `filter_out` | OpenAI, *Introducing SWE-bench Verified*, 13 Aug 2024. The original `cdn.openai.com/introducing-swe-bench-verified/` URLs for the CSVs no longer resolve (the annotation-instructions PDF there still does). | Research mirror `github.com/mariushobbhahn/SWEBench-verified-mini`, file `data/external_data/ensembled_annotations_public.csv`, pinned to commit `80e15f699bb426e352aa1d829b554314d246a17a` (2024-12-27). `npm run data:annotations` re-downloads it from that commit. | SHA-256 `d2743650f6b2d31eeaf6d9952c3766b022930964d9d9452fc35cfbeb1967827c`. `npm run data:annotations -- --check` verifies the committed file offline; CI re-fetches from the pinned commit and requires byte identity. Row count and columns match OpenAI's published description; the derived filter reproduces the published 68% rejection rate. |
| `swebench_test.parquet` (not committed; 12 MB) | The SWE-bench test split (2,294 instances): issue text, gold patch, test patch, FAIL_TO_PASS / PASS_TO_PASS | Princeton NLP, `princeton-nlp/SWE-bench` on Hugging Face (Jimenez et al., ICLR 2024) | `https://huggingface.co/datasets/princeton-nlp/SWE-bench/resolve/<revision>/data/test-00000-of-00001.parquet`; CI pins revision `e48e2bd1e9fecd5bbd641e9414ac59da9f2e69f6` | The 30-case evaluation set and the calibration file are rebuilt from it in CI and must be byte-identical to the committed `data/eval/*.json`. |

The per-annotator file OpenAI also published (`samples_with_3_annotations_public.csv`) is not mirrored anywhere reachable; that is why human–human agreement cannot be computed in this project.
